# BURGH Corporate Website

A responsive five-page corporate website for BURGH, presenting BURGH HOMES and BURGH ENERGY through one cohesive brand system.

## Routes

- `/` — Home
- `/about` — About BURGH
- `/homes` — BURGH HOMES
- `/energy` — BURGH ENERGY
- `/contact` — Contact and enquiry form

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The enquiry form opens a reviewed email draft addressed to `mustaphakadri@yahoo.co.uk`. Instagram is intentionally presented as an unlinked handle until the official profile is verified.
